# Lead Hunter & Insights - Estrategia de Monetización

Este script genera archivos JSON listos para ser importados en herramientas de ventas (CRMs) o campañas de email.

## Pasos para generar dinero:
1. **Identifica un nicho:** (ej. empresas buscando software de arquitectura).
2. **Ejecuta el script:** Genera leads con necesidades específicas.
3. **Personaliza:** Usa el archivo generado para enviar correos ultra-personalizados.
4. **Cierra:** Cobra por tus servicios de consultoría, desarrollo o marketing.

## Script: lead_generator.py
Este script simula la detección de oportunidades de negocio en un mercado.
