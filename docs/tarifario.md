# Tarifario de Servicios - Villa Nueva (Perú)

Estos precios están diseñados para ser competitivos y accesibles para Mypes peruanas, eliminando la barrera de entrada mientras se mantiene una percepción de profesionalismo técnico.

## 1. Paquete "Primeros Auxilios Digitales"
*   **Precio:** S/. 350 (pago único)
*   **Objetivo:** Eliminar el error "Sitio lento" y asegurar que el contacto sea directo.
*   **Incluye:** Optimización de carga, configuración de Google Maps Local y auditoría de seguridad.

## 2. Paquete "Presencia de Alto Rendimiento"
*   **Precio:** S/. 950 (50% anticipo / 50% entrega)
*   **Objetivo:** Conversión.
*   **Incluye:** Rediseño de landing page, formularios de contacto directos a WhatsApp, optimización para móviles y hosting rápido.

## 3. Plan "Socio Digital" (Mensual)
*   **Precio:** S/. 150 / mes
*   **Objetivo:** Tranquilidad.
*   **Incluye:** Hosting incluido, copias de seguridad, actualizaciones de seguridad, cambios de menú/precios mensuales y reporte de leads.

---
*Nota: Los precios están expresados en Soles peruanos para facilitar la negociación local.*
